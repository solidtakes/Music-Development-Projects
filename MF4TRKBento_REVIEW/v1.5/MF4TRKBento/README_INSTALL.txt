MF4TRKBento v1.5 EXP
====================
Live 13 Beta and Twister hardware validation pending.

Close Live and back up your working MF4TRKBento remote-script folder.
Install only this folder, then restart Live with the existing Twister ports.
Rollback by restoring the saved MF4TRKBento folder with Live closed.
See TEST_AND_ROLLBACK.md at the ZIP root for the full checklist.

Default rows: RClip / Pan / Mute / Sends.
Hold a row's first encoder and turn its last to cycle
RClip / Arm / Solo / Pan / Mute / Sends / Stop.
One Arm and one Solo are allowed. Single taps are exclusive.
Hold one Arm or Solo button and press another to add tracks.
Arm is red. Solo is blue. Active states flash.
Hold Arm and tap directly above for Solo. Reverse the order for Mute.

E1 held + E16 turn scrolls tracks. E1 held + E12 turn scrolls scenes.
Both use four detents per step. E16 held first + E1 enters/exits alt mode.
Clip and scene launch on release. Pan push centers. Alt fourth Pan is Master.

Sends are purple and numbered from the top Sends row. Turn adjusts.
Mute is yellow for monitor Auto/Off, blue for monitor In, with a mute ring.
Alt fourth Sends, Arm, Solo and Mute cells are inactive.
Stop is red. A short press stops the track on release. Alt fourth Stop
stops the whole Set. Holds of 0.5 seconds or more cancel Stop.

Routing: CC0-15, rotary channel 12, push channel 11.
Continue with the existing Utility settings and controller mode.
