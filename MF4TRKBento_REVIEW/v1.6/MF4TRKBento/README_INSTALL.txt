MF4TRKBento v1.6 EXP
====================
Live 13 Beta and Twister verification pending.

Close Live and back up the installed MF4TRKBento folder. Install only
this folder and keep the existing MIDI ports and Utility profile.
See TEST_AND_ROLLBACK.md in the archive root.

Pan and Sends are available on tracks with audio output. Alt fourth Pan
controls Master. Pan press centers. Sends use top-to-bottom assignment and
press is inert. Sends RGB uses value 48 from the Twister Extended palette.

Hold Arm, tap above for Solo or below for Mute.
Hold Solo, tap above for Mute or below for Record Arm.
Hold Mute, tap below for Solo.
Use encoders in the same column; the held module must be pressed first.
Solo stays blue. Arm stays red.

Existing navigation, module switching and release-only Stop apply.
Close Live and restore the saved v1.5 folder to roll back.
